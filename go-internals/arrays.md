# Массивы (`[N]T`): значение, копирование и отличие от слайса

## 1. Устройство и тип

`[3]int` — массив из **ровно трёх** `int`, включённых в значение. Длина входит в тип: `[3]int` и `[4]int` — разные типы. Слайс `[]int` — другое значение, концептуально содержащее указатель/длину/ёмкость.

Массив имеет фиксированный размер; его элементы находятся внутри значения массива. `len` и `cap` массива равны N. Значение `[N]T` сравнимо, только если `T` сравним.

## 2. Передача по значению — копия всех элементов

```go
func f(a [3]int) { a[0] = 99 }
func main() {
    x := [3]int{1, 2, 3}
    f(x)
    fmt.Println(x) // [1 2 3]
}
```

В отличие от `[]int`, изменение `a[0]` действует на **локальную копию**. В случае больших массивов копирование потенциально дорого, хотя оптимизации компилятора могут изменить физический способ передачи.

## 3. Указатель на массив vs слайс

```go
func changeArray(a *[3]int) { a[0] = 7 }
func changeSlice(s []int)   { s[0] = 8 }
```

Оба меняют исходные элементы, но через разную модель: `*[3]int` — указатель на весь массив фиксированной длины, `[]int` — доступная область backing array.

Срез `x[:]` создаёт слайс над элементами `x`. Изменение `x[:][0]` изменит `x[0]`.

## 4. Сравнение массивов

```go
a := [2]int{1, 2}
b := [2]int{1, 2}
fmt.Println(a == b) // true
```

Для `[2][]int` оператор `==` между массивами запрещён: элементы `[]int` несравнимы. Для проверки содержимого слайса используй `slices.Equal` или явную логику.

## 5. `range` копирует итерируемый массив в ряде случаев

```go
a := [3]int{1, 2, 3}
for i, v := range a {
    if i == 0 { a[1] = 99 }
    fmt.Print(v, " ")
}
// 1 2 3
```

При `range a`, если вычисляются значения элементов, выражение массива вычисляется до начала цикла и обходится его копия. При `range a[:]` обходится слайс, а изменения исходных элементов могут наблюдаться на следующих шагах. Есть специальный случай: если используется только индекс (или значение не используется), компилятор по спецификации может не вычислять массив целиком.

## 6. Размер, стек/куча и производительность

Не утверждай «массив всегда в стеке»: escape analysis может разместить его в куче. Массивы удобны для фиксированных небольших значений и ключей `map`, например `[16]byte`; для динамического размера подходит слайс.

## 7. Частые вопросы

- Почему `[3]int` нельзя передать в аргумент `[]int` без среза `[:]`?
- Что изменится, если у метода receiver `[N]T` по значению, а не `*[N]T`?
- Что будет при `range` по массиву, если в теле модифицируется исходный массив?
- Почему `map[[16]byte]V` возможен, а `map[[]byte]V` — нет?
